Mac 电池状态性能对比跑分 —— 检测「坏电池拖慢整台电脑」

零依赖 · 只用 macOS 自带工具 开源 · 源码明文可审阅 不联网 · 不改系统设置

这是什么

电池故障的 Mac 即使插着充电器,macOS 也可能认为供电能力不足,把 CPU 限速到 50% 甚至更低、禁用睿频。本工具把系统自报告的限速状态和 实际计算性能跑分放在同一次运行里记录,在换电池前后各跑一次并对比, 就能用数据回答:「我的 Mac 变慢,是不是电池造成的?」

我该下载哪个脚本

在「终端」里执行:

sysctl -n machdep.cpu.brand_string

输出以 Apple M 开头(M1/M2/M3/M4)→ 下载 Apple Silicon 版; 否则(i5 / i7 / i9 等)→ 下载 Intel 版。选错了脚本会直接拒绝运行并提示,不会跑错。

使用方法

  1. 关掉浏览器、聊天软件等可关的程序,插好充电器;
  2. chmod +x macbench-apple.sh 然后运行 ./macbench-apple.sh(约 1 分钟,可选 --freq 需输密码);
  3. 给这次测试起个名字,例如「坏电池接电源」;
  4. 换电池之后,在同样条件下再跑一次,命名如「换新电池后」;
  5. 对比两次结果: 
    ./macbench-apple.sh compare results/result_旧.txt results/result_新.txt

如何判读结果

现象结论
单核/多核比值 ≈ 0.50性能被限制了一半,典型的无电池降频
多核比值明显低于单核比值睿频被禁用,或部分核心被限制
CPU_SPEED_LIMIT < 100强证据:macOS 明确报告了主动限速
内存带宽比值 ≈ 1.0内存未被限制(正常,降频主要影响 CPU)
所有比值 ≈ 1.0 且无限速两种状态性能无差别
严谨说明:CPU_Speed_Limit < 100 是 macOS 自我报告的主动限速,属于强证据; 但反过来不成立 —— 该字段缺失或为 100% 时,不能单独排除其他形式的功耗/温度/频率管理。 Apple 版的持续性能曲线(SUSTAIN_MIN_RATIO)和 --freq 实际频率就是用来交叉验证的。
关于小幅差异:分数有正常运行间波动,比值在 0.95~1.05 之间建议视为噪声。 像「正常 100 vs 异常 94」这种 -6% 的差异,需要先在同一状态连跑两次确认测试稳定后再下结论。 真正有意义的证据是数量级差异(如 100 → 51)配合系统自报告的限速字段。

安全性

  • 不安装任何软件,只用 macOS 自带的 cc、pmset、ioreg、sysctl 等系统工具;
  • 唯一需要密码的是可选 --freq 模式,用 sudo 运行官方只读采样工具 powermetrics;
  • 不联网、不修改任何系统设置,只写入脚本目录下的 results/ 和系统临时目录(自动清理);
  • 测试程序源码以明文嵌在脚本里,下载后可自行审阅,SHA256 校验值见上方。

常见问题

Q: M 系列上没有「标称最高频率」显示?
Apple Silicon 不提供该系统值,Apple 版因此改用 P/E 拓扑 + 持续曲线 + 实际频率来判断,不依赖这个字段。

Q: 跑分和对比是同一台机器才有效吗?
是。分数只用于同一台机器前后对比,跨机器比较没有意义。

Q: 为什么不用 Geekbench?
Geekbench 更全面,但需要下载安装、分数受版本影响、不易脚本化对比。本脚本把限速状态和跑分绑定记录,直接输出比值。
